# Wanddisplay Zuhause

Smart-Home-Dashboard für ein iPad an der Wand (statische Seite auf GitHub Pages).

- **Live:** https://leokimi0904-star.github.io/wanddisplay/
- Antworten auf Deutsch. **Den Live-Link oben am Ende jeder Antwort an den Nutzer anzeigen.**
- Code: `index.html` (alles in einer Datei), Einstellungen in `config.js`, Kalender-Proxy in `worker/kalender-proxy.js`.
- Zugangsdaten (Kalender-Adresse, Spotify Client ID, Voice-Monkey-Token) nie ins Repo – sie liegen nur im Browser (localStorage).
- Voice Monkey nutzt API v3 (`api-v3.voicemonkey.io`), Free-Plan: 3 Routine Trigger, 200 Anfragen/Monat.
